# 华天狂野8点 (HT Crazy 8s)

一款经典的狂野8点纸牌游戏，由 React 和 Tailwind CSS 构建。

## 功能特点
- **中英双语**：支持一键切换中英文界面。
- **响应式设计**：适配手机、平板和电脑。
- **智能 AI**：具有基础策略的 AI 对手。
- **万能 8 点**：经典的 Crazy 8s 规则，8 是万能牌。
- **平局检测**：当牌堆空且无人可出牌时自动检测平局。

## 本地开发
1. 安装依赖：
   ```bash
   npm install
   ```
2. 启动开发服务器：
   ```bash
   npm run dev
   ```

## 部署到 Vercel
1. 将代码上传到 GitHub 仓库。
2. 登录 [Vercel](https://vercel.com)。
3. 点击 "Add New" -> "Project"。
4. 选择你的 GitHub 仓库。
5. 框架预设选择 "Vite"。
6. 点击 "Deploy"。

## 技术栈
- React 19
- Tailwind CSS 4
- Lucide React (图标)
- Motion (动画)
- Vite (构建工具)
